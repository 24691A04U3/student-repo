# 🍔 FoodCo Data Analytics Bootcamp

Welcome to the analytics team at **FoodCo** — a fast-growing Indian food-delivery startup in Bengaluru, Mumbai, Delhi, Hyderabad, Pune, and Chennai.

Over the next **10 days** you'll take the company's raw, messy data and turn it into clean reports, dashboards, and SQL-powered answers that leadership actually uses. **One dataset, ten days** — the Excel sheet you clean in Week 1 is the *same* data you query with SQL in Week 2. Nothing is throwaway.

> **This is a 100% hands-on course.** There are no lecture slides to memorise. Every day you open a folder, read the scenario, and *build* the answer.

---

## 📅 How each day works

1. **Pull** the latest from the course repo (a new day's folder appears each morning — see below).
2. Open that day's folder and read **`instructions.md`** — it has the business scenario and your exact task.
3. Build the deliverable using the data files in the folder.
4. **Submit your work as a Pull Request** (you'll learn how on Day 0).

### ⚠️ New folders unlock every day
You will **not** see all 10 folders at the start. Each morning your trainer releases that day's folder. Your job is to `git pull` to get it — which is exactly how real engineering teams receive new work. If today's folder isn't there yet, pull again.

👉 **First time with Git/GitHub? Start with [`Day_00_Git_Onboarding/`](Day_00_Git_Onboarding/instructions.md) and [`GIT_WORKFLOW.md`](GIT_WORKFLOW.md).**

## 🗺️ The 10-day journey

| Day | Module | What you'll learn | Tool |
|----|--------|-------------------|------|
| 00 | Setup | Fork, clone, pull, commit, Pull Requests | Git & GitHub |
| 01 | Foundations | Structured vs semi vs unstructured data; the analytics lifecycle | Excel / any viewer |
| 02 | Foundations | The 4 types of analytics + a data-ethics & PII audit | Google Sheets |
| 03 | Advanced Excel | Cleaning dirty data with **Power Query** | Excel |
| 04 | Advanced Excel | **VLOOKUP / INDEX-MATCH / XLOOKUP** | Excel |
| 05 | Advanced Excel | **Pivot Tables & Charts** — the ops dashboard | Excel |
| 06 | Advanced Excel | **Macros & VBA** — automate the daily report | Excel |
| 07 | SQL | **SELECT / WHERE / GROUP BY / HAVING** | DB Browser for SQLite |
| 08 | SQL | **Joins** (INNER / LEFT / RIGHT / FULL) | SQLite |
| 09 | SQL | **Window functions** (RANK, LAG, running totals) | SQLite |
| 10 | SQL | **CTEs + capstone** executive report → BI | SQLite + Power BI/Tableau |

**Weeks 1–2 build on each other.** The clean table from Day 3 feeds the lookups in Day 4, the pivots in Day 5, the macros in Day 6 — and the same company data, loaded into a database, powers the SQL in Days 7–10.

## 🧰 Setup

Everything you need to install is in **[`SETUP.md`](SETUP.md)**. The short version:
- **Excel** (or Google Sheets) for the Excel module.
- **[DB Browser for SQLite](https://sqlitebrowser.org/)** (free, no server) for the SQL module.
- **Git** + a free **GitHub account** — set up on Day 0.

The data lives in **[`datasets/`](datasets/)** (released before the SQL week) with a full **[data dictionary](datasets/DATA_DICTIONARY.md)**.
